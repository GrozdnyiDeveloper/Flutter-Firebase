# Мобильное приложение на Flutter/Dart с использованием платформы Firebase

В данном репозитории представлено небольшое мобильное приложение для хранения списка книг, написанное на языках программирования Flutter и Dart с использованием возможностей облачной платформы Firebase. 

Firebase представляет собой облачную платформу для разработки мобильных и веб-приложений, предоставляющая набор готовых инструментов и сервисов, которые позволяют снизить нагрузку на клиентские устройства и упростить развёртывание новых приложений. 

## В приложении используются следующие инструменты платформы Firebase
- Firebase Auth - используется для регистрации и авторизации аккаунтов через почту и пароль (имеются интеграции с сервисами гугл)
- Firebase Firestore - является NO-SQL базой данных, использующаяся для хранения списков книг пользователей в формате справочников и документов внутри них, содержащих набор не стандартизированных атрибутов
- Firebase Storage - файловая система использующаяся для добавления функционала загрузки и хранения файлов (приемущественно изображений)

Само приложение предназначено для сохранения и редактирования списка книг со стороны пользователя.
